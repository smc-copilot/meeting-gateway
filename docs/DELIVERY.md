# 交付与投产顺序

本包交付的是 `nodeskclaw-meeting` 首版实现源码，以及装入既有 monorepo 的 Backend / Portal 增量模块。不是整个 nodeskclaw 仓库的克隆，也不是已连接企业账号的托管服务。

## 开箱检查

1. 验证 ZIP 的 SHA-256；解压后核对 `SOURCE-MANIFEST.json`（它不把自身计入哈希清单）。
2. 阅读根目录 README 的生产前置项和已知验证边界。
3. 将目录放入仓库根，先运行安装器 `--dry-run`，审查后 `--apply`。这两个命令不会调用腾讯。
4. 联网生成依赖锁，在隔离 PostgreSQL 上迁移。设置独立随机加密与服务凭证，不复用 Backend JWT 密钥。
5. 启用 Portal 并构建；Bootstrap 仅授予管理权限，另行设置业务访问授权。
6. 先联调两个通道的只读能力、OAuth、STS、Webhook、身份与撤权，再开启创建、MCP、企业同步和媒体下载。

## 必须现场执行的门槛

| 门槛 | 必要证据 |
|---|---|
| Backend / Portal 集成 | 目标分支安装差异、原功能回归、实际登录与停用员工测试、Vue 类型检查及 Vite 构建 |
| PostgreSQL | 隔离测试库的真实迁移、跨进程领取与锁、并发幂等、刷新与租约回收测试 |
| Tencent | 两类应用分别授权、真实只读内容与原生文件核对、回调/STS、批准的测试会议创建与结果核对 |
| MCP 客户端 | 指定智能体的完整授权与 PKCE 流程、初始化与工具调用、撤销和错误受众测试 |
| 运维 | Docker 构建、HTTPS、实际出口 IP、白名单、备份/恢复、私有持久存储、监控与告警 |
| 安全 | 静态检查、独立代码评审、SSRF/DNS、跨组织对象替换、日志脱敏、回调重放和下载撤权测试 |

没有上述证据，不把 `1.0.0rc1` 标为生产验收完成。自动化的本地通过项和外部跳过项分别记录在 `reports/FINAL-VERIFICATION.md`。

## 数据和回滚

安装器回滚只恢复代码接入，不删除数据库或会议文件。生产先关闭敏感功能，停止 Worker，再按照审核过的数据备份策略处置。Alembic downgrade 会移除新服务表，只应在可丢弃测试库或已有确认备份的回退流程中使用；不能在生产盲目执行。普通业务删除使用软删除。

## 首版明确限制

只创建普通一次性会议；修改/取消、周期会议、公开应用市场、腾讯客户端 JSAPI 页面、OA 任务处理、RAG、ASR、S3 后端不属于本包首版实现。元宝纪要可读取正文，但没有已核验原生导出时拒绝下载，不伪造腾讯原始文件。应用禁用不提供无审核的一键重新启用；客户/凭证轮换与新连接须经管理员配置确认。

管理页面为完整可编辑 Vue 源码模块，表单按实际 DTO Schema 驱动；本环境只执行了 TS 语法解析，不把它标成 Vue 模板/类型/构建通过。PostgreSQL 是生产运行方式，SQLite 是本地测试辅助，不是双数据库生产支持承诺。
